# Map Glyph Reference

## Glyph Types

- **THORN** (`GlyphWW`): `|||` symbol
- **DRAGON** (`GlyphOO`): `(*)` symbol  
- **CHEVRON** (`GlyphAA`): `/^\` symbol
- **Ocean**: Ocean regions (special glyph type)
- **NoGlyph**: Regions with no glyph

## Faction-Specific Glyph Requirements

### Yellow Sign (YS) - Desecration Spellbooks
Yellow Sign must desecrate one area of each glyph type:
- Desecrate CHEVRON area (GlyphAA)
- Desecrate DRAGON area (GlyphOO)
- Desecrate THORN area (GlyphWW)

### Fleshmason (FM) - Setup Constraint
**CRITICAL**: Fleshmason can ONLY setup in regions with THORN or DRAGON glyphs:
- Valid: GlyphWW (THORN) or GlyphOO (DRAGON) regions
- Invalid: GlyphAA (CHEVRON), Ocean, or NoGlyph regions

When FM sets up in a valid region (THORN/DRAGON), it automatically places Screaming Wall(s) in that region during setup.

### Fleshmason (FM) - Terrifying Shriek Requirement
For the Terrifying Shriek spellbook, FM must have Screaming Walls in areas containing at least 3 different glyph types (any combination of CHEVRON, DRAGON, THORN).

## Implementation Notes

In `Map.scala`, FM's starting regions are filtered to only THORN/DRAGON:
```scala
case FM => regions.%(r => r.glyph == GlyphWW || r.glyph == GlyphOO)
```

This ensures players can only select valid setup regions for Fleshmason.
